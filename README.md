# Argo-CD-1- GitOps on Kubernetes (AWS EC2)
Argo CD Demo – GitOps on Kubernetes (AWS EC2) A hands-on demo of GitOps-based continuous delivery using Argo CD. This repository holds the Kubernetes manifests for a sample application deployed in the vamsi namespace on a Kubernetes cluster running on AWS EC2. Argo CD watches this repo and keeps the cluster in sync with whatever is committed here.
